# practice4-sqlx

Запуск:
1. Скопируй содержимое этой папки в проект.
2. Убедись, что Docker Desktop запущен.
3. В папке проекта запусти:
   docker-compose up -d
4. Подождать пока контейнер инициализирует БД (файл users.sql автоматически выполнится при старте).
5. Установить зависимости и запустить программу:
   go mod tidy
   go run main.go
